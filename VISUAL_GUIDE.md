## 🔐 Authentication Flow

```
┌──────────────────────────────────────────────────────────┐
│  One-Time Setup (You do this once)                       │
├──────────────────────────────────────────────────────────┤
│                                                           │
│  1. Create Google Cloud Project                          │
│     ↓                                                     │
│  2. Enable Google Calendar API                           │
│     ↓                                                     │
│  3. Create OAuth 2.0 Credentials                         │
│     → Get Client ID                                      │
│     → Get Client Secret                                  │
│     ↓                                                     │
│  4. Use OAuth Playground                                 │
│     → Authorize Calendar scope                           │
│     → Get Refresh Token                                  │
│     ↓                                                     │
│  5. Add to .env.local                                    │
│     GOOGLE_CLIENT_ID=...                                 │
│     GOOGLE_CLIENT_SECRET=...                             │
│     GOOGLE_REFRESH_TOKEN=...                             │
│                                                           │
└──────────────────────────────────────────────────────────┘
                           │
                           ↓
┌──────────────────────────────────────────────────────────┐
│  Runtime (Automatic for each request)                    │
├──────────────────────────────────────────────────────────┤
│                                                           │
│  API Route receives request                              │
│     ↓                                                     │
│  Initialize OAuth2Client                                 │
│     ↓                                                     │
│  Set credentials with refresh token                      │
│     ↓                                                     │
│  OAuth2Client automatically:                             │
│  - Exchanges refresh token for access token              │
│  - Handles token expiration                              │
│  - Refreshes access token when needed                    │
│     ↓                                                     │
│  Make Calendar API call with valid access token          │
│     ↓                                                     │
│  Success! Event created                                  │
│                                                           │
└──────────────────────────────────────────────────────────┘
```
